# Portfólio Acadêmico

Portfólio acadêmico desenvolvido como atividade prática do curso de **Análise e Desenvolvimento de Sistemas**.

O projeto tem como objetivo apresentar um pouco dos conhecimentos adquiridos durante os estudos de **Desenvolvimento Web**, utilizando HTML e CSS.

## Tecnologias Utilizadas

- HTML5
- CSS3

## Sobre o Projeto

A página apresenta:

- Informações acadêmicas;
- Tecnologias estudadas;
- Conhecimentos adquiridos em HTML e CSS;
- Experiência e evolução durante os estudos.

O projeto foi desenvolvido com foco na aplicação dos fundamentos de **estruturação semântica com HTML** e **estilização com CSS**, buscando manter um código simples, organizado e de fácil compreensão.

## Objetivo Acadêmico

Esta atividade faz parte do processo de aprendizado e prática dos fundamentos de Desenvolvimento Web, servindo também como registro da evolução durante o curso.
