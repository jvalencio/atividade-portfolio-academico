Confira abaixo um pouco do que aprendi sobre Desenvolvimento Web.

TECNOLOGIAS

Durante meus estudos, comecei a desenvolver conhecimentos fundamentais para a criação e estilização de páginas web.

HTML

Utilizado para estruturar o conteúdo de uma página web, organizando textos, imagens, links e outros elementos de forma semântica.

CSS

Responsável pela apresentação visual das páginas, permitindo trabalhar com cores, fontes, espaçamentos, posicionamento e diferentes layouts.

MINHA EXPERIÊNCIA

A experiência de aprender Desenvolvimento Web tem sido um processo de evolução constante. Comecei entendendo os fundamentos do HTML e, posteriormente, passei a explorar o CSS para transformar estruturas simples em páginas mais organizadas e visualmente agradáveis.

Mesmo ainda estando no início da minha jornada, já consigo perceber minha evolução na forma de estruturar páginas, organizar códigos e pensar na experiência de quem irá utilizar um site.
